# Proton

## What is a proton?
A **proton** is a particle with a positive electric charge. Protons are found in the nucleus of an atom.

## Why is it important?
The number of protons determines which chemical element an atom belongs to. For example:
- 1 proton: hydrogen
- 6 protons: carbon
- 8 protons: oxygen

If the number of protons changes, the element changes too. That is a nuclear change, not an ordinary chemical reaction.

A proton is made from smaller particles called quarks. See [[Nucleus]] for the bigger picture.
