# Chemistry Glossary

Use these as plain-language starting points. The linked lessons provide the fuller explanations, equations, examples, and caveats.

| Term | Meaning |
|---|---|
| **Accuracy** | How close a measurement is to an accepted or reference value. |
| **Activation energy** | The energy barrier associated with a reaction pathway. |
| **Acid** | In the Brønsted-Lowry model, a species that donates a proton. |
| **Anion** | A negatively charged ion. |
| **Anode** | The electrode where oxidation occurs. |
| **Atom** | A unit of an element with a nucleus and electrons. |
| **Atomic number** | The number of protons in a nucleus; it identifies the element. |
| **Avogadro constant** | 6.02214076 × 10²³ entities per mole. |
| **Base** | In the Brønsted-Lowry model, a species that accepts a proton. |
| **Boiling** | Vapor formation throughout a liquid when vapor bubbles can grow under the conditions. |
| **Bond dissociation energy** | Energy required to separate bonded atoms in a specified process and state. |
| **Catalyst** | A substance that provides an alternative reaction pathway and speeds a reaction without being consumed overall. |
| **Cation** | A positively charged ion. |
| **Chemical bond** | A stable arrangement of atoms arising from interactions and quantum behavior, not a physical string. |
| **Chemical element** | A type of atom defined by its number of protons. |
| **Chemical equilibrium** | A dynamic state in which forward and reverse reaction rates are equal. |
| **Chemical formula** | A symbolic description of the kinds and counts or ratios of atoms in a species. |
| **Chemical kinetics** | The study of reaction rates and factors that affect them. |
| **Compound** | A pure substance containing two or more elements chemically combined in a definite ratio. |
| **Concentration** | Amount of a component relative to a specified amount of mixture or solution. |
| **Covalent bond** | A bond involving electron density shared across bonded atoms. |
| **Density** | Mass divided by volume. |
| **Dipole** | A separation of positive and negative charge; molecular dipoles have magnitude and direction. |
| **Dissolution** | The process by which particles of a solute disperse among solvent particles. |
| **Electron** | A negatively charged elementary particle described in atoms by quantum states. |
| **Electron affinity** | The energy change associated with adding an electron to a gaseous species; check the sign convention used. |
| **Electron cloud** | A picture of where an electron may be detected, not a physical fog. |
| **Electron density** | A description of how electron probability is distributed through space in a quantum system. |
| **Electronegativity** | A measure of how strongly an atom attracts shared electron density in a bond. |
| **Electrolyte** | A substance that provides mobile ions in solution or when molten and can conduct electricity. |
| **Enthalpy** | A thermodynamic state function H = U + pV, useful for constant-pressure processes. |
| **Entropy** | A state function related to accessible microscopic arrangements and energy distribution. |
| **Equilibrium constant (K)** | A quantity describing equilibrium composition at a specified temperature and standard-state convention. |
| **Exothermic** | Describes a process that transfers heat from the system to surroundings under the stated conditions. |
| **Formal charge** | A Lewis-structure bookkeeping assignment of electrons, not necessarily a measured charge. |
| **Gibbs free energy** | A thermodynamic quantity; at constant temperature and pressure, ΔG helps assess reaction favorability. |
| **Ground state** | The lowest-energy allowed quantum state of a system. |
| **Half-life** | Time for half the nuclei in a large radioactive sample to decay on average. |
| **Heat** | Energy transferred because of a temperature difference. |
| **Hydrogen bond** | A directional attraction commonly involving hydrogen bonded to N, O, or F and a suitable electron-rich site. |
| **Ideal gas** | A model treating gas particles as negligible in volume with no attractions except during collisions. |
| **Intermolecular** | Between separate molecules. |
| **Intramolecular** | Within a molecule. |
| **Ion** | An atom or group of atoms with net electric charge. |
| **Ionization energy** | Energy needed to remove an electron from a specified gaseous atom or ion. |
| **Isomer** | One of multiple compounds with the same molecular formula but different structures or spatial arrangements. |
| **Isotope** | A version of an element with a particular neutron count. |
| **Kinetic energy** | Energy associated with motion. |
| **Limiting reactant** | Reactant that is used up first and determines the theoretical maximum product amount. |
| **Molar mass** | Mass per mole, commonly expressed in g/mol. |
| **Molarity** | Amount of solute per litre of final solution, in mol/L. |
| **Mole** | Amount containing exactly 6.02214076 × 10²³ specified entities. |
| **Molecule** | A defined group of atoms held together in a chemical arrangement. |
| **Neutron** | A particle in most atomic nuclei with no net electric charge. |
| **Nucleus** | The tiny, dense center of an atom containing protons and usually neutrons. |
| **Orbital** | An allowed quantum state for an electron, often pictured as a probability distribution, not a path. |
| **Oxidation** | Electron loss in the bookkeeping picture, or an increase in oxidation state. |
| **Oxidation state** | A formal assignment used to track electron redistribution; not always the actual atomic charge. |
| **pH** | A logarithmic measure related to hydrogen-ion activity. |
| **Polar covalent bond** | A covalent bond with unequal electron sharing. |
| **Precipitate** | A solid that forms from a solution. |
| **Precision** | How closely repeated measurements agree with one another. |
| **Probability** | A measure of how likely an outcome is. |
| **Probability density** | A quantity describing how detection probability is distributed through space. |
| **Product** | A species formed in a chemical reaction. |
| **Proton** | A positively charged particle in a nucleus; proton number identifies the element. |
| **Quantum mechanics** | The physical theory used to describe very small systems, including electrons and atoms. |
| **Reactant** | A species present before and consumed or transformed during a reaction. |
| **Reduction** | Electron gain in the bookkeeping picture, or a decrease in oxidation state. |
| **Resonance** | A way of representing a delocalized electron distribution using multiple Lewis structures. |
| **Solubility** | The equilibrium amount of a substance that can dissolve under specified conditions. |
| **Solute** | A component dispersed in a solution. |
| **Solvent** | The medium in which a solute dissolves. |
| **Specific heat capacity** | Energy needed per unit mass to raise temperature by one degree, under specified conditions. |
| **Stoichiometry** | Quantitative relationships among reactants and products from balanced equations. |
| **Thermal energy** | An informal term for energy associated with microscopic motion and interactions. |
| **Thermodynamics** | The study of energy, heat, work, entropy, and reaction favorability. |
| **Transition state** | A high-energy arrangement along a reaction pathway. |
| **Valence electrons** | Outer electrons especially important in bonding and chemical reactions. |
| **Wavefunction** | A mathematical description of a quantum state; its squared magnitude relates to probability density. |
